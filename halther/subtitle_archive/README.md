## 配布ファイル
- subtitles.sqlite：subtitles（動画・内容単位）、subtitle_files（全字幕ファイル）、metadata。
- subtitles.csv：動画・内容単位。概要、作物、長文詳細、代表字幕原文を含む。
- subtitle_files.csv：翻訳・改訂・コピーを含む全件の字幕原文。
- subtitles.html：検索・分類・年・並び順・ページ送り。インターネット接続やサーバー不要。
- records.json：Webページと同じ内容のデータ。

## 整理方針
コードはファイル名のn＋数字、a＋数字を保持し、ゼロ埋めも残す。コード不明の例外はファイル名を保持する。
同じコード・同じ分類の字幕を一つの記録にまとめ、日本語を含む標準ファイル名を優先する。
同じコードでも分類が異なる場合は別記録とし、管理IDを主キーにする。関連コードは収集履歴の元フォルダから取得するが、ファイル名のコードを書き換えない。
同じ本文を持つ異なるコードは削除しない。duplicate_ofに同一本文の参照先を記録する。
日本語のない翻訳版もsubtitle_filesに全件保持。subtitleは時刻・改行・BOMを含めたデコード原文。original_bytesは元ファイルのバイト列そのもの。
CSVはExcelで開きやすいUTF-8 BOM付き。セル内の改行を保持したため、物理行数と件数は一致しない。CSVはパーサーで読み込む。

## 時期・分析の限界
撮影時期の本文を優先し、将来予定、栽培適期、回顧の時期を区別する。年が本文にない場合は更新年と前後の記録から推定し、根拠に明記。
更新日だけから旬を補わない。年月のソート用に開始年月・終了年月を保存する。回顧を主時期から除いたものは表示欄に回顧と記載。
概要は約200文字を目安に編集。情報の少ない記録や空ファイルは短い。詳細は概要と本文の関連記述を組み合わせた長文。
作物は日本語字幕の名称を辞書照合し、表記揺れを統合。言及、計画、失敗、比較対象も含む。歌・旅の記録は空欄。
字幕の誤字と話者の仮説は修正せず保存。一般的な農学の事実検証を行ったデータベースではない。
