# 沖縄のダイコン栽培と自然農

作成・資料確認：2026年10月12日。
daikon_okinawa.html は文献、名護の月別気象データ、自然農動画字幕からの調査・考察。
article.css / article.js と同じフォルダに保存すれば、オフラインでも閲覧・日付計算が可能。

- references.json：15件の資料。発行主体・時期・出典URL・用途と限界。
- climate_summary.json：名護の月別値から1991〜2020年・2016〜2025年の算術平均。気象庁公表の平年値そのものではない。
- observed_season_2024_2025.json：主要な字幕の経過を照合した2024年9月〜2025年3月の月別気象値。
- video_evidence.json：主要15件の時期・根拠と、該当する字幕番号・時刻・原文。

元の気象・字幕データベースは隣接する nago_climate/ と subtitle_archive/。
ページ内で「文献で確認」「畑の観察」「推察・提案」を区別。
播種・収穫の暦は自然農の試験案であり、地域全体の公式推奨暦ではない。
青首・短形を11月上〜中旬に主作とする案を提示。島ダイコンの晩抽性、土の硬さ、密度・草との競合に応じて確認する。
撮影時期が推定された字幕は明示し、畑の実測気温と名護観測所の気温を区別。
文献のPDFは再配布せず、出典元へリンク。
