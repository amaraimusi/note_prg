## 重要な留保
ユーザーの「未収穫」という申告とn129（2024年12月中旬）の収穫・調理字幕は食い違う。片方を修正せず、別区画・方法・同定の確認が必要と記事に記載。
沖縄県の現行ダイジョ専用公式栽培暦・施肥基準は未確認。地域研究者の解説と宮古島の試験条件を区別。
2010年文献の収穫日は本文とTable 2表注に不一致がある。月単位で解釈。
宮古島の施肥栽培・台湾在来系統で、4–6月植付けの地下芋乾物重に有意差なし。3–4月を名護自然農の最善月と実証したものではない。
自然農への作型、草管理、低い支柱、試し掘り・小試験は提案。自然農の比較試験や品種別耐風ランキングは確認できていない。
貯蔵温度、観測所の空気温度、畑の地温は区別する。
