# 沖縄のオクラ栽培と自然農

調査日：2026-10-14（日本時間）。ローカルHTML。出典16件、追加でタキイの生育解説への直リンク。
慣行の公表作型と自然農への推察を明確に区別。自然農の最適日・多収性を実証したものではない。

## ファイル
- okra_okinawa.html / article.css / article.js：記事、気温グラフ期間切替、関連字幕検索。オフライン利用可（外部出典リンクは接続が必要）。
- references.json：確認済み一次資料の書誌情報・適用条件。
- climate_summary.csv / json：1991〜2020、2016〜2025の月別独自平均。気象庁の正式平年値ではない。各指標の有効件数を_n列に記録。
- video_evidence.json：代表字幕にオクラ／おくらを含む内容単位を抽出。全文・元の時期根拠を保持。
- video_excerpts.csv：オクラ／おくらを含む字幕ブロック。行によって前後の説明を含まないため、全文と照合して読む。
- trial_log.csv / germination_log.csv：記入用の空テンプレート。成功データを生成していない。

## 再計算
元CSV：../nago_climate/nago_monthly_1990_2026.csv
元字幕：../subtitle_archive/records.json
気象はperiod_status=completedかつquality=normal/quasi_normalを指標別に抽出。年ごとの月値を単純平均、未丸め値を配布、表示だけ小数1桁。
2026年途中月を長期平均に含めない。月平均の最低／最高は日最低／日最高の月平均で、月の極値ではない。
字幕の年推定・母の畑／本人の畑・予定と実績を区別。映像の直接確認は未実施。
作成スクリプトは指定の作業フォルダに保存。
