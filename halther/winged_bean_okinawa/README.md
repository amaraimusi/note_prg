# 沖縄のシカクマメ栽培と自然農
作成日：2026-10-12。若莢の露地栽培を対象。

winged_bean_okinawa.html と article.css / article.js は相対リンクのみで表示し、外部ライブラリや通信を必要としません。文献リンクを開く場合だけ通信が必要です。

## 気候集計
入力は ../nago_climate/data.json。指定作業フォルダ「沖縄の年間気温調査」の成果を利用。
1991–2020（各月30値）と2016–2025（各月10値）の完了月を対象。normalとquasi_normalのみ。指標別nを保存。
月平均気温、日最低気温の月平均、日最高気温の月平均、月降水量を月別に単純平均。公式平年値ではない。
JSON/CSVの数値は小数2桁、記事表示は小数1桁。mean_ge_20_countは各年の月平均気温が20℃以上の件数で、日数ではない。2026年10月の途中値を含めない。

## 字幕
入力は ../subtitle_archive/records.json。指定作業フォルダ「字幕データ調査」の成果を利用。
シカクマメ・四角豆・しかくまめ・うりずん・ウリズンで代表字幕を検索。39件、n175/n174の重複を除くと38内容。代表字幕の一致箇所前1ブロック、後3ブロックまでをJSONに保存。
記事は16記録を解釈つきで選択。ファイル名・時刻と時期根拠はJSONを参照。映像未再視聴、株・区画の同一性は断定しない。

## 文献と推察
references.jsonにURL・確認範囲を保存。本文未確認書誌は数値の根拠にしない。
4月上旬〜下旬の自然農主作は作業仮説。ウリズンと現地自家採種系統を比較する。
field_log.csvは入力欄の見出しのみで、架空の栽培結果を含まない。
