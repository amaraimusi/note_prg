02 / HOW TO READ

読み解くための三つの区別

アフリカ起源 ≠ 完全置換

アフリカでの成立は、ネアンデルタールやデニソワ人からの遺伝的寄与と両立します。

古い化石 ≠ 確定した直系祖先

形態や年代が近くても、祖先・姉妹系統・後まで残った別系統のどれかは簡単に決まりません。

論文の提案 ≠ 学界の合意

特に最新の人口史モデルは前提に依存します。年表では証拠と未解決点を併記しました。

年表の西暦は研究の発表・議論の時期です。化石が生きていた「何万年前」という年代は、各項目の詳細に分けて記載しています。

05 / METHOD

調査範囲と限界

調査対象：1970年〜2026年9月27日に公表された研究と、その時期の見解の変化。中心はホモ・サピエンスの成立・祖先集団・旧人との関係。遠い祖先と初期ホモ属の研究は、系統観の変化を理解するために含めた。文化人類学全般の歴史ではない。

方法：出版社、PubMed、研究機関の公開論文・抄録・公開抜粋、専門家総説を優先した論点別の文献調査。主要な転換点の選択的年表であり、全論文の系統的レビューでも、研究者の賛否を集計した調査でもない。検索対象語は modern human origins / multiregional / assimilation / African origin / ancient DNA / structured stem / Homo ancestors と個々の論文題名。各行の旧見解は比較のための要約であり、その時代の全研究者が共有した意見ではない。

確認範囲：出典表 checked_scope に記録。全文を読めなかった資料もあり、公開抄録・抜粋で確認できた内容を中心に採録した。原著の提案と、複数研究を踏まえた編集上の位置づけを区別する。status_as_of_2026 は引用論文に基づく定性的整理で、数値化した合意率ではない。

年代：year_start / year_end は研究・議論の時期。ancient_age_text は化石・祖先集団の過去の年代で、混同しない。オンライン先行公開が確認できればその年を採用。複数年の項目は発見から論文化、またはオンライン年から巻号年を含む。±値、上限・下限、当時の推定は原文の意味を保ち、異なる方法の誤差を同じ信頼区間とみなさない。

最新範囲：調査基準日は2026年9月27日。採録した最新の個別原著は2026年9月9日公開。2026年の通年を網羅したものではなく、この日までの全研究を収集したという意味でもない。2026年の主要検索では原著まで確認できたものを採録し、未査読プレプリントは年表に採録しなかった。

重要な区別：①アフリカ起源と完全置換は同義ではない。②世界規模の古典的多地域進化とアフリカ内の集団構造は別のモデル。③mtDNAの共通祖先と全ゲノム・種全体の共通祖先は別。④化石の最古記録は種の誕生日ではない。⑤姉妹群や近縁種と直系祖先は別。⑥化石種の名称、遺伝的集団、研究上のモデル集団は一対一には対応しない。

解釈：大きな流れは、化石による系統の復元から、遺伝学・年代測定・古代分子を統合した集団史へ。旧説の全面否定だけでなく、支持の追加、適用範囲の限定、交雑の組み込み、年代の更新が重なってきた。アフリカでの成立と旧人からの遺伝的寄与は両立する。一つの化石種をサピエンスの確定した直接祖先として一本の系譜に並べる段階にはない。
